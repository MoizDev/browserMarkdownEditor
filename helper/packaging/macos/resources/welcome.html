VaultAgent

VaultAgent lets the Markdown editor in your browser talk to the AI coding agents already on this Mac: Claude Code, Codex and OpenCode.

It is a small background helper. It has no window, no Dock icon and no menu-bar icon, and it only answers the editor on this computer.

The agents it starts can read and change the notes in the vault you open in the editor, and their edits land in the editor live. They also run with the same access to this Mac as in your terminal — commands, files, the web — without asking first.
