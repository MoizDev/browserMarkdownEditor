Symbols Nerd Font Mono (SymbolsNerdFontMono.woff2)
=================================================

This file is the "Symbols Nerd Font Mono" font from the Nerd Fonts project,
release v3.5.1 (NerdFontsSymbolsOnly.zip, SymbolsNerdFontMono-Regular.ttf),
converted to WOFF2 and with its TrueType hinting removed. No glyph was added,
removed or redrawn. Nothing else about the font changed.

  https://github.com/ryanoasis/nerd-fonts
  https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1

The editor's terminal uses it only as a fallback for icon code points (Private
Use Area and a few power symbols), so that prompt themes such as Powerlevel10k,
Starship and oh-my-zsh show icons instead of empty boxes when the user's own
font has none. Ordinary text is never drawn from it.

The font is an aggregate of several icon sets, each under its own licence. The
Nerd Fonts project's own README lists them:
